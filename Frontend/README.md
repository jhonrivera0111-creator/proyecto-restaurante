# Casa Verde — Frontend

SPA en React 19 + Vite que consume la API del backend (`/api/v1`).

Las instrucciones completas de instalación, ejecución y pruebas están en el [README principal](../README.md).

Comandos rápidos (desde esta carpeta, con el backend corriendo en `localhost:5020`):

```bash
npm install         # primera vez
npm run dev         # http://localhost:5173
npm run test:run    # pruebas Vitest
npm run build:web   # build de producción en dist/
```
